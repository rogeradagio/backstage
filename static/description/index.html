Backstage

Keeps a Magento store in sync with Odoo fulfilment

Pickups, shipments, invoices, credit notes, cancellations and returns reach Magento as idempotent events, so customers are kept informed. Sellable stock is exported per Magento source, and web pickup transfers go through a store receipt with incident handling.

  • To review: the only list to watch. Each item says what happened and what to do.
  • Configuration: connection, sources, pickup stores and stock in one place, with a test mode that sends no customer e-mails.
  • Stock in Magento on every product: what is sent to each source and why.
